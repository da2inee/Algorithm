# Hash (해시) 정리

## 1) 해시란?
- 키(Key)를 해시 함수로 계산해서 특정 인덱스에 저장/조회하는 방식
- 평균적으로 삽입, 삭제, 조회가 빠름
- 파이썬에서는 `dict`, `set`이 대표적인 해시 기반 자료구조

## 2) 시간 복잡도
- 평균: `O(1)` (삽입/조회/삭제)
- 최악: `O(n)` (충돌이 심할 때)

## 3) 충돌(Collision) 처리
- 서로 다른 키가 같은 인덱스로 매핑되는 현상
- 대표 처리 방식
  - Chaining: 같은 버킷에 리스트(또는 연결 리스트)로 저장
  - Open Addressing: 비어 있는 다른 칸을 찾아 저장

## 4) 언제 쓰면 좋은가?
- 빠른 존재 여부 확인이 필요할 때
- 중복 제거가 필요할 때
- 빈도수 카운팅이 필요할 때

## 5) 파이썬 기본 패턴

### 5-1. 빈도수 카운팅
```python
arr = [1, 3, 1, 2, 3, 1]
count = {}

for x in arr:
    count[x] = count.get(x, 0) + 1

print(count)  # {1: 3, 3: 2, 2: 1}
```

### 5-2. 빠른 포함 여부 확인
```python
nums = [5, 2, 9, 1]
s = set(nums)

target = 2
if target in s:
    print("존재함")
```

### 5-3. `list`의 `in` vs `set`의 `in`
- 문법은 같아도 내부 동작이 다름
- `x in list`: 앞에서부터 순차 탐색 -> `O(n)`
- `x in set`: 해시 기반 탐색 -> 평균 `O(1)`
- 그래서 포함 여부를 많이 확인하는 문제는 `set`이 훨씬 유리함

```python
arr = ["a", "b", "c", "d"]
s = {"a", "b", "c", "d"}

print("c" in arr)  # 리스트: 순차 탐색
print("c" in s)    # 셋: 해시 탐색
```

## 6) 연습 문제 유형
- 숫자 카드(존재 여부 판별)
- 문자열 등장 횟수 세기
- 중복 원소 제거
- 교집합/차집합 계산
